Markdown은 몇 가지 기호로 글의 구조를 표현하는 방식입니다. 복잡한 편집 도구 없이도 문장과 생각에 집중할 수 있습니다.

<!--more-->

## 세 가지 색으로 기록하기

어두운 청록 배경에 **핫핑크**와 `일렉트릭 퍼플`로 포인트를 줍니다. 미스트 틸은 링크와 참고 설명을 연결하는 서브 컬러입니다. 밝은 모드에서는 같은 계열을 짙게 조정해 글씨가 흐려지지 않도록 했습니다.

> **미스트 틸 · 참고와 연결**
>
> 더 읽어 볼 자료는 [우아한형제들 기술블로그](https://techblog.woowahan.com/27864/)처럼 링크로 연결합니다. 관련 설명이나 참고 자료를 덧붙일 때 사용합니다.
{: .note }

> **핫핑크 · 핵심과 주의**
>
> 한 문단에서 꼭 기억할 내용만 강조합니다. **모든 문장을 강조하면 중요한 문장이 묻힙니다.**
{: .important }

> **일렉트릭 퍼플 · 코드와 팁**
>
> `# 제목`으로 큰 제목을 만들고, 문단 사이에는 빈 줄을 넣어 보세요. 바로 따라 해 볼 수 있는 팁이나 코드에 사용합니다.
{: .tip }

### 한 문단에 색 섞어 쓰기

오늘의 목표는 **작게라도 끝까지 기록하기**입니다. `keep_a_note()`로 배운 내용을 남기고, 막히는 부분은 [참고 자료](https://techblog.woowahan.com/27864/)를 연결합니다. **결론은 핫핑크**, `실행할 코드는 퍼플`, 링크는 미스트 틸로 구분합니다.

```markdown
오늘의 목표는 **작게라도 끝까지 기록하기**입니다.
`keep_a_note()`로 배운 내용을 남기고,
막히는 부분은 [참고 자료](https://techblog.woowahan.com/27864/)를 연결합니다.
```

색을 직접 지정하지 않아도 `**굵게**`, 백틱, 링크 문법에 맞춰 색이 자동으로 적용됩니다.

### Markdown에서 강조 상자 쓰기

인용문 아래에 다음처럼 한 줄을 붙이면 됩니다. `.note`는 미스트 틸, `.important`는 핫핑크, `.tip`은 퍼플입니다.

```markdown
> **참고**
>
> 관련 자료와 배경 설명을 적습니다.
{: .note }

> **핵심 내용**
>
> 꼭 기억할 문장을 적습니다.
{: .important }

> **실습 팁**
>
> `# 제목`을 입력하고 결과를 확인해 보세요.
{: .tip }
```

# 제목과 문단

글의 제목은 파일 맨 위의 `title`에 적습니다. 본문에서 `#`로 입력한 가장 큰 제목에는 아래 구분선이 생깁니다. `##`와 `###`로 하위 항목을 나누면 됩니다. 오른쪽 목차도 이 제목들을 따라 자동으로 만들어집니다.

```markdown
# 가장 큰 제목

## 오늘 배운 것

문단 사이에는 빈 줄을 하나 둡니다.

### 직접 해 본 예시

작은 예시로 이해한 내용을 확인합니다.
```

강조하고 싶은 단어는 **굵게**, 조금 다른 목소리를 주고 싶을 때는 *기울여* 적을 수 있습니다.

## 목록으로 생각 정리하기

- **핵심 발견:** 문장을 짧게 나누면 읽기 쉬워집니다.
- **직접 확인:** `#`, `##`, `###`로 제목 크기를 비교해 봅니다.
- **다음 기록:** [제목과 문단](#제목과-문단)으로 돌아가 구조를 다듬습니다.

순서가 있는 과정이라면 숫자를 사용합니다.

1. 해결하려는 문제를 한 문장으로 적습니다.
2. 가장 작은 예시를 만들어 봅니다.
3. 결과와 생각이 달라진 부분을 기록합니다.

## 코드를 함께 남기기

코드 앞뒤에 백틱 세 개를 넣고 언어 이름을 적으면 문법이 강조됩니다. 코드 오른쪽 위의 복사 버튼도 자동으로 붙습니다.

키워드는 핑크, 함수는 블루, 문자열은 앰버, 숫자와 논리값은 퍼플로 구분됩니다. 주석은 차분한 회청색으로 표시합니다. 코드에서는 문법을 쉽게 읽을 수 있도록 색을 더 다양하게 사용합니다.

### Python · 점수 요약

첫 줄의 백틱 뒤에 `python`을 적습니다.

```python
from statistics import mean

# 결측값을 제외하고 평균과 표본 수 계산
def summarize(scores, digits=2):
    valid = [x for x in scores if x is not None]
    if not valid:
        return {"mean": None, "n": 0}
    return {"mean": round(mean(valid), digits), "n": len(valid)}

result = summarize([72, 85, None, 91, 88])
print(f"평균: {result['mean']}, 표본 수: {result['n']}")
```

### R · 같은 데이터 요약

R 코드는 백틱 뒤에 소문자 `r`을 적으면 됩니다.

```r
# 결측값을 제외하고 평균과 표본 수 계산
summarize_scores <- function(scores, digits = 2) {
  valid <- scores[!is.na(scores)]
  if (length(valid) == 0) {
    return(list(mean = NA_real_, n = 0))
  }
  list(mean = round(mean(valid), digits), n = length(valid))
}

scores <- c(72, 85, NA, 91, 88)
result <- summarize_scores(scores)
cat("평균:", result$mean, "표본 수:", result$n, "\n")
```

긴 코드도 화면을 벗어나지 않고 코드 영역 안에서 가로로 스크롤됩니다.

> **실습 팁**
>
> 두 예제 모두 평균은 `84`, 표본 수는 `4`입니다. `scores`의 값을 바꾸거나 결측값을 추가하고 결과를 비교해 보세요.
{: .tip }

**핵심은 실행 결과만 남기지 않는 것**입니다. 어떤 값을 바꿨는지 `scores`와 함께 기록하고, 관련 설명은 [인용과 링크](#인용과-링크)에 연결해 보세요.
